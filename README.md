# System Monitor

Десктопное приложение для macOS (Apple Silicon), которое показывает, чем занят ноутбук.

**Что умеет (v1 + v2).** Всё на одной странице со скроллом, меню слева прокручивает к нужному разделу.

- Обзор: полоса с главными цифрами, клик ведёт к разделу.
- Процессор: загрузка с графиком, каждое ядро, load average, температура датчиков.
- Память: разбивка как в «Мониторинге системы» (программы, wired, сжатая, кэш), давление памяти, swap и список процессов по памяти.
- Сеть: скорость с графиком, шлюз, DNS, внешний IP по кнопке, интерфейсы с IP и MAC, программы с открытыми соединениями и открытые порты.
- Диски: свободное место на каждом томе, график чтения и записи, а ещё анализ и очистка (v2):
  - скан домашней папки, «Программ» или любой папки: карта диска, переход вглубь, крупные файлы, то, что давно не менялось;
  - удаление программ вместе с «хвостами» в ~/Library, как в AppCleaner;
  - быстрые чистки: кэши программ, кэши Go/npm/Cargo/Homebrew/Xcode, node_modules и target в заброшенных проектах,
    старые версии IDE JetBrains, логи и дампы .hprof, Docker (контейнеры, образы, кэш сборки; тома не трогаются).
  Удаляется всё только в Корзину (кроме Docker и очистки самой Корзины, это навсегда и спрашивается отдельно).
  Системные папки и данные Docker удалить из приложения нельзя. Чтобы скан видел всё, дай приложению
  «Полный доступ к диску» в Системных настройках, кнопка для этого есть в разделе.
- Устройства: батарея Mac (заряд, оставшееся время, мощность, здоровье, циклы) и заряд Bluetooth‑устройств: наушников (у AirPods отдельно левый, правый и кейс), мыши, клавиатуры, трекпада. Последний известный заряд запоминается, поэтому отключённые наушники тоже видно.
- Процессы: поиск, сортировка по CPU, памяти и диску, завершение процесса.
- Docker: все контейнеры с CPU и памятью, старт, стоп, перезапуск и логи.
  Работает с Docker Desktop, OrbStack, Colima и Rancher Desktop.
- Строка меню: загрузка CPU и RAM видна всегда. Крестик прячет окно, а приложение продолжает работать.

## Панель в вырезе (cyclop)

В папке `notch/` лежит [cyclop](https://github.com/akalikbergenov/cyclop) (MIT) — панель, которая выпадает из выреза MacBook при наведении. К его вкладкам (музыка, полка, буфер, календарь, перевод…) добавлен третий рельс с вкладками System Monitor:

- **Система**: CPU с графиком, память и давление, скорость сети, топ‑3 процесса, батарея и аптайм.
- **Диски**: место на томах, чтение и запись.
- **Устройства**: заряд Bluetooth‑наушников, мыши, клавиатуры.
- **Docker**: контейнеры с CPU и памятью, запуск и остановка.
- **Серверы**: статус VPS из окна System Monitor; упавший сервер виден красной точкой и уведомлением.

Анализ и очистка диска и полный список процессов в панель не помещаются — их открывает кнопка, она запускает окно System Monitor.

Данные даёт `sysmon-helper` (`crates/sysmon-core`) — тот же Rust‑код, что у окна. Панель запускает его дочерним процессом и опрашивает только открытую вкладку; серверы проверяются в фоне раз в минуту. Ненужную вкладку можно убрать в настройках панели, вместе с её опросом.

Скачать: артефакт `Cyclop-SystemMonitor-macOS-arm64` в [Actions](../../actions), распаковать в «Программы» и выполнить `xattr -cr /Applications/Cyclop.app`. Нужна macOS 15+. Собрать самому: `cd notch && ./Scripts/bundle.sh` (нужны Rust и Command Line Tools), приложение появится в `notch/build/Cyclop.app`.

Обновить cyclop из оригинала: `git subtree pull --prefix=notch https://github.com/akalikbergenov/cyclop.git main --squash`.

## Установка

1. Открой вкладку [Actions](../../actions), выбери последний успешный запуск **Build macOS** и скачай артефакт `SystemMonitor-macOS-arm64`.
2. Открой `.dmg` и перетащи приложение в «Программы».
3. Приложение не подписано сертификатом Apple, поэтому при первом запуске macOS его заблокирует. Один раз выполни:

   ```sh
   xattr -cr "/Applications/System Monitor.app"
   ```

## Запуск из исходников

Нужны [Rust](https://rustup.rs) и Node.js 20+.

```sh
npm install
npm run tauri dev     # запуск в режиме разработки с перезагрузкой
npm run tauri build   # сборка .app и .dmg в src-tauri/target/release/bundle
```

## Как устроен код

Приложение на [Tauri 2](https://tauri.app): логика на Rust, интерфейс — обычная веб‑страница на TypeScript, которую показывает системный WebView (поэтому приложение весит ~10 МБ, а не 200 как Electron).

```
crates/sysmon-core/src/   сбор данных без интерфейса, общий для окна и панели
  metrics.rs   метрики через crate sysinfo
  docker.rs    Docker через crate bollard
  devices.rs   Bluetooth‑устройства и их заряд через system_profiler и ioreg
  servers/     серверы по SSH (v3)
  bin/helper.rs  sysmon-helper: те же данные для панели в вырезе, строками JSON
src-tauri/src/
  main.rs      точка входа, просто вызывает lib::run()
  lib.rs       сборка приложения: трей, фоновые задачи, команды для фронтенда
  metrics.rs   событие "metrics" раз в секунду
  docker.rs    событие "docker" раз в 3 секунды
  netinfo.rs   шлюз, DNS, порты и соединения через route, scutil и lsof, событие "netinfo"
  devices.rs   событие "devices" раз в 30 секунд
  servers.rs   событие "servers" и уведомления
  tray.rs      иконка и меню в строке меню macOS
  disk/        анализ и очистка диска (v2)
    scan.rs      параллельный скан папки (rayon), событие "disk-scan" с прогрессом
    guard.rs     что удалять нельзя, удаление в Корзину (crate trash)
    apps.rs      программы и их «хвосты» в ~/Library по bundle id
    cleanup.rs   быстрые чистки и Docker prune
src/
  main.ts      интерфейс: вкладки, карточки, таблицы
  disk.ts      интерфейс анализа и очистки диска
  treemap.ts   раскладка карты диска
  chart.ts     мини‑графики на canvas
  types.ts     типы данных, которые присылает Rust
```

Rust общается с интерфейсом двумя способами:

- **События** (`app.emit("metrics", &snapshot)` в Rust → `listen("metrics", ...)` в TS) — Rust сам присылает свежие данные.
- **Команды** (`#[tauri::command] fn kill_process` в Rust → `invoke("kill_process", { pid })` в TS) — интерфейс просит Rust что‑то сделать.

Структуры с `#[derive(Serialize)]` автоматически превращаются в JSON, а `#[serde(rename_all = "camelCase")]` переименовывает поля `swap_used` → `swapUsed`, как принято в JS.
