**Починена потеря заготовок.** Заготовка, добавленная без имени, делала
`snippets.json` нечитаемым для самого приложения: вкладка пустела, а следующее
добавление записывало эту пустоту поверх файла. Теперь безымянные записи
читаются, как и задумано форматом, — а файл, сломанный ручной правкой,
приложение никогда не перезаписывает: панель показывает предупреждение, клик
по нему открывает файл.

Спасибо за точные отчёты — [#14](https://github.com/akalikbergenov/cyclop/issues/14)
и [#7](https://github.com/akalikbergenov/cyclop/issues/7).
